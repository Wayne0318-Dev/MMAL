# 模具机台对照

根据《转模记录9月份.xlsx》（2026 年 9 月 1–14 日）整理的查询工具：输入模具编号，查看这 14 天里实际装卸过的机台。

这是**历史装机记录**，不是模具规格书。模具没出现在某台机器上，不代表不能装。编号疑点没有自动合并，等确认后再改。

## 本地运行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:43127

## 数据从哪来

- 原始表：`data/转模记录9月份.xlsx`
- 解析结果：`src/data/dataset.json`
- 解析脚本：`scripts/build-dataset.py`

改过 Excel 或解析规则后：

```bash
pip install openpyxl
npm run data
```

## 读表方式（待确认）

每个工作表是一天，表内分 A 班 / B 班。列是：机台、机种品名、模具编号、类别上/下、时间、备注。

当前按下面规则解析，任何一条不对都可以改：

1. **上** = 把模具装到机台上，**下** = 从机台拆下来。
2. 机台格空白 = 同一班次继承上一行机台。
3. `S240122后`、`前模S240122` 归到主编号 `S240122`，前/后当套别标签。
4. 疑似笔误只打标，不改号。

详情见应用里的「待确认」页。
